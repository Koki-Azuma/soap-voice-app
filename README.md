# 音声入力SOAPノート (Voice SOAP Notes)

マイクからの音声入力をリアルタイムでテキスト化し、医療・リハビリ・看護の臨床キーワードをもとに **S（主観的情報）**・**O（客観的情報）**・**A（評価）**・**P（計画）** へ自動振り分けするWebアプリケーションです。

---

## 🌟 主な機能

1. **ワンクリック音声認識（Web Speech API）**
   - 「録音開始」ボタンでマイクからの音声入力を開始。
   - 発話中の暫定テキストと確定テキストをリアルタイムで画面に表示。
   - 「録音停止」ボタンで停止し、全体テキストを確認・編集可能。
2. **キーワードベースのSOAP自動振り分け**
   - **S（Subjective：主観的情報）**：自覚症状（痛い、つらい、しびれる、だるい、不安、眠れない、訴えなど）を含む文
   - **O（Objective：客観的情報）**：検査値・測定値・バイタル（ROM、MMT、度、cm、kg、mmHg、回、秒、歩行、握力、腫脹など）を含む文
   - **A（Assessment：評価・分析）**：分析・判断（考えられる、原因、問題、改善、低下、制限、リスク、評価など）を含む文
   - **P（Plan：治療計画）**：計画・指導（プログラム、目標、実施、継続、指導、週、セット、退院、自主トレなど）を含む文
   - キーワードにマッチしなかった文は「未分類」カードに安全に格納。
3. **柔軟な編集＆カルテ連携**
   - 振り分けられた各文はクリックして直接インライン編集可能。
   - ドロップダウンでセクション間（例: S ⇄ O ⇄ A ⇄ P）を手動移動可能。
   - ワンクリックで電子カルテ貼り付け用フォーマットに一括コピー可能。
   - 各セクションごとの個別コピーにも対応。
   - 項目削除・手動追加機能。
4. **テスト用サンプル文章ボタン**
   - マイクが使えない環境でも、「例文を入力」ボタンですぐに臨床文章での変換挙動を試せます。

## 🚀 起動方法

### おすすめ方法（最も確実・マイク許可がスムーズ）
ブラウザの音声認識機能（Web Speech API）はセキュリティ仕様上、`localhost` での動作が最も推奨されます。

1. **Windowsの場合**
   `start.bat` をダブルクリックするだけで、ローカルサーバーが起動しブラウザが開きます。

2. **コマンドライン（Python / Node.js）の場合**
   ```bash
   # Pythonの場合
   cd C:\Users\violi\.gemini\antigravity\scratch\soap-voice-notes
   python -m http.server 8000
   ```
   ブラウザで `http://localhost:8000` を開きます。

3. **直接開く場合**
   `index.html` をダブルクリックして、Google Chrome または Microsoft Edge で開いてください。
